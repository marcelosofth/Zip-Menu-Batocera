Applying ZipMenu to Batocera:

Copy the files to /userdata/system/
zipmenu-hook.sh
zipmenu-joy.py
zipmenu-launch.sh
custom.sh

* In the Batocera CMD, type:

cd /userdata/system
chmod +x zipmenu-hook.sh zipmenu-launch.sh zipmenu-joy.py

echo '#!/bin/bash' > /userdata/system/custom.sh
echo '/userdata/system/zipmenu-hook.sh' >> /userdata/system/custom.sh
chmod +x /userdata/system/custom.sh

bash /userdata/system/zipmenu-hook.sh

chmod +x /userdata/system/zipmenu-joy.py
ls -l /userdata/system/zipmenu-joy.py

chmod +x /userdata/system/zipmenu-launch.sh
/userdata/system/zipmenu-hook.sh

sed -i 's/\r$//' /userdata/system/zipmenu-hook.sh
chmod +x /userdata/system/zipmenu-hook.sh
rm -f /userdata/system/zipmenu-boot.log
bash /userdata/system/zipmenu-hook.sh; bash /userdata/system/zipmenu-hook.sh
